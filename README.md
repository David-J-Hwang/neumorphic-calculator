# Neumorphic Calculator

## 1. 개요
  - 밝고 부드러운 느낌의 Neumorphism 디자인 스타일이 들어간 계산기 프로젝트다.

## 2. 기술스택
  - React + Vite
  - TypeScript
  - TailwindCSS
  - Vitest + React Testing Library
  - math.js
  - frankfruter 환율 API

## 3. 주요기능
  - [v] 기본 계산기
    - [v] 사칙연산
    - [v] 소수점 계산
    - [v] 퍼센트 계산
    - [v] 괄호 계산
    - [v] 부호변경 버튼(+/-)
    - [v] AC/C/Backspace
    - [v] 계산기록 저장(오른쪽 패널/drawer)
    - [v] 키보드 입력
    - [v] 모든 계산 수식부분이 보이도록 UI 개선하기
    - [v] 계산기록 재사용 및 전체 삭제
    - [v] 안전한 계산식 파싱 및 계산(eval 미사용)
    - [v] 입력 유효성 검사: 연산자 연속 입력 방지, 소수점 중복 입력 방지, 잘못된 괄호 입력 방지
    - [v] 결과값 기반 연속 계산
    - [v] 계산 결과 포맷팅: 긴 숫자 처리, 천 단위 구분, 소수점 자릿수 보정
    - [v] 오류 상태 처리: 잘못된 수식, 0으로 나누기
  - [ ] 공학용 계산기
  - [ ] 날짜 계산기
  - [ ] 단위변환 계산기
  - [ ] 부동산 계산기
  - [ ] 건강관련 계산기: BMI, 기초대사량(BMR), 일일권장칼로리(TDEE)
  - [ ] 프로그래머용 계산기
  - [ ] 시간 계산기: 시간 더하기, 평균수명 기반 남은 시간
  - [ ] 환율 계산기

## 4. 기타
- 기존의 JavaScript로 개발한 프로젝트를 React 라이브러리를 사용해서 프론트엔드를 개선하는 방향으로 작업을 진행중이다.
